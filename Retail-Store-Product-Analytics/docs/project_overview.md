# Product Analytics — Project Overview

## Objective
Analyze product-level retail transactions and convert raw transaction data into actionable business insights.

## Business questions
1. What are the top-selling products?
2. Which products generate the highest revenue?
3. Which products generate the highest profit?
4. Which categories contribute the most revenue and profit?
5. How do sales change by month?
6. How do discounts relate to profit?
7. Which products should management prioritize?

## Dataset summary
- Transactions: 5,000
- Products: 20
- Categories: 5
- Stores: 5
- Units sold: 10,866
- Revenue: ₹13,329,368.50
- Profit: ₹4,181,423.50
- Average margin: 30.10%

## Deliverables
- Python analysis script
- Interactive Streamlit dashboard
- Static dashboard preview
- Analysis output tables
- Visualization images
- Documentation
